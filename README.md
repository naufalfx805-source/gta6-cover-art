A standalone offline web app that turns user photos and captions into iconic GTA 6 multi-panel cover art with Vice City color grading and extruded 3D typography.

## Run it

```sh
node serve.ts
```

Then open `http://localhost:8080` in your desktop browser.

## Features

- **Multi-Panel Comic Grid**: 5-panel Vice Iconic, 6-panel Leonida Grid, 3-panel Action Triptych, and Solo Poster layouts.
- **Vice City Color Grading**: Preset filters including Vice Sunset, Neon Heat, Miami Golden Hour, and Gritty Noir.
- **GTA Poster Typography**: Authentic multi-pass 3D extruded shadow lettering with dual-tone outer strokes.
- **Targeted Panel Control**: Click any panel to upload, zoom, and pan individual photos.
- **Standard Export Ratios**: Instant export to full-resolution PNG in Square (1080x1080), Portrait (1080x1350), and Landscape (1920x1080).
- **100% Offline & Private**: Zero external network dependencies, runs entirely in the local browser canvas.
