## What it does

Vice Cover Studio is a fully offline web app:
- **Loads photos locally** — nothing uploaded to any server
- **Multi-panel layouts**: 5-Panel Hero, 3-Panel Triptych, 2-Panel Split, Solo
- **Vice City color grading**: Sunset, Neon Night, Golden Hour, Noir
- **GTA typography**: bold lettering with layered 3D depth and outer glow
- **PNG exports**: 1080x1080, 1080x1350, 1920x1080

## Quick Start

```bash
node serve.ts
```
Open http://localhost:8080 in Chrome.

## Tips for best results

- **High-contrast photography**: Sunset skylines, palm trees, neon signs, and sports cars yield the most iconic GTA aesthetics.
- **5-Panel Hero layout**: Use a vertical character or vehicle shot in the primary panel, with complementary action shots in the right rail.
- **Short punchy captions**: Keep main titles between 2 to 4 words (e.g. *VICE CITY DREAMS*, *NEON NIGHTS*, *GOLDEN HEIST*) to maximize the 3D extrusion impact.
- **Export shortcut**: Press `Ctrl+Enter` (or `Cmd+Enter` on Mac) anywhere in the editor to immediately download your cover.
