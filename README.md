## What it does

Vice Cover Studio is a fully offline web app:
- **Loads photos locally** — nothing uploaded to any server
- **Multi-panel layouts**: 5-Panel Hero, 3-Panel Triptych, 2-Panel Split, Solo
- **Vice City color grading**: Sunset, Neon Night, Golden Hour, Noir
- **GTA typography**: bold lettering with layered 3D depth and outer glow
- **PNG exports**: 1080x1080, 1080x1350, 1920x1080

## Quick Start

```bash
node serve.ts
```
Open http://localhost:8080 in Chrome.

## Tips for Best Results

- **High Contrast Photos**: Use photos with distinct silhouettes, vibrant sunsets, or night cityscapes.
- **Hero Panel Framing**: In the 5-Panel layout, the left panel serves as the primary character / vehicle showcase.
- **Short Impactful Titles**: Keep captions between 2 to 4 words (e.g. *VICE CITY DREAMS*, *OCEAN DRIVE HEIST*) for optimal typography scaling.
- **Keyboard Shortcut**: Press `Ctrl + Enter` (or `Cmd + Enter` on macOS) to instantly export your cover art.
